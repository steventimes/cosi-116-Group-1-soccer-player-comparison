# Soccer player activity comparison

Run `python3 -m http.server 8000 --bind 127.0.0.1` from this directory and open http://127.0.0.1:8000.

Compare seasons, drag a shared rectangle, or select a preset. Hover over either field for matching local counts. Rates show their counts and a dash when there are no attempts. D3 supplies the shared color scale and SVG overlay construction.
