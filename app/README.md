# 球员赛季热图

这个原型对比同一球员在两个赛季的有球动作位置，以及传球和射门比例。当前数据是两个虚构球员的五个示例赛季，用于开发交互，不代表真实比赛结论。

在项目根目录运行。

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory app
```

用现代浏览器打开 http://127.0.0.1:8000 。页面使用 JavaScript 模块和本地 JSON，需要通过这个服务打开，不能直接双击 HTML。

选一个球员和赛季，再选择对照年份。在任意球场上拖动矩形，两个球场会显示同一区域，右侧比率按选区内的动作重新计算。悬停可以查看局部计数。赛季按钮支持左右方向键，区域菜单和重置按钮也可以用键盘操作。

## 修改入口

| 文件 | 用途 |
| --- | --- |
| `index.html`、`styles.css` | 页面结构和样式。 |
| `src/app.js` | 统计条、局部明细和交互状态。 |
| `src/pitch.js` | 热力图绘制、球场线条和选区覆盖层。 |
| `src/model.js` | 数据校验、选区判断、计数和密度网格。 |
| `data/demo.json` | 固定种子的示意动作数据。 |
| `scripts/generate_demo.py` | 重新生成同一份示意数据。 |

没有前端运行依赖，也不调用外部 API。坐标是球场长宽的百分比。传球完成率使用传球尝试数作为分母，进球转化率和射正率使用射门数作为分母。没有尝试时显示横杠。

数据校验会拒绝缺少结果、非法坐标、重复球员或赛季，以及同一球员赛季内重复的动作 ID，并在页面显示具体位置。相同坐标可以对应不同动作，不会因此判成重复。当前数据没有动作 ID，不能据此声称已检测真实重复事件。真实数据接入、全部球员赛季总览、跨球员比较和原始动作明细仍在后续待办中。

## 验证

模型检查只需要 Node.js 18 或更新版本。

```bash
node --test app/test/model.test.js
```

浏览器检查使用已有的 Playwright 和 Chrome 或 Chromium，脚本会启动并关闭自己的本地服务。

```bash
node app/scripts/verify_browser.cjs
```

如果这些工具不在默认安装位置，可分别用 `PLAYWRIGHT_MODULE` 和 `BROWSER_EXECUTABLE` 指定模块路径和浏览器可执行文件。截图与结果写入 `app/artifacts/`，不属于应用源码。
